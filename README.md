# Connect LB CRM – Property Management System

A Laravel-based CRM/ERP system developed for real estate and property management operations.

##  Project Overview
Connect LB CRM is a property management dashboard designed to manage buildings, lands, units, contracts, clients, and financial operations through an advanced admin system.

## Features
- Property & unit management
- Financial tracking dashboard
- Dynamic analytics and reporting
- Role-Based Access Control (RBAC)
- Custom filtering by date ranges
- Contract and payment tracking
- Responsive admin interface

##  Technologies Used
- Laravel
- PHP
- MySQL
- Blade
- JavaScript
- Bootstrap
- Carbon
- Eloquent ORM

##  Backend Features
- Optimized SQL queries and aggregations
- Dynamic dashboard metrics
- MVC architecture
- Database relationship management
- Secure authentication and permissions
